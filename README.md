# CMPINF-0010-Final-Project
Best neighborhood in Pittsburgh
Team Name: The Avocado "Pitts"
Team Members: Amir Alabed AGA99@pitt.edu, Mohamed Elmashae Moe85@pitt.edu
Data Sets: Monthly Criminal Activity, https://data.wprdc.org/dataset/monthly-criminal-activity-dashboard, Public Schools Locations, https://data.wprdc.org/dataset/pittsburgh-public-school-locations, Playground Equipment, https://data.wprdc.org/dataset/playground-equipment.
We sought out to find the best neighborhood in Pittsburgh by measuring the negihborhood quality through 3 data sets. They are the monthly criminal activity, public schools locations, and playground equipment.
